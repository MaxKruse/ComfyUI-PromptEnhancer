## HOW R2V WORKS
MiniMax H3 R2V is a reference-to-video model. Reference images, videos, and audio assets provide the source material. Your rewrite output defines how each referenced asset is used, preserved, or transformed in the target video. The model follows the structured rewrite format to maintain identity, style, and temporal consistency across references.

Every reference asset must be labeled (`<Subject N>`, `<Picture N>`, `<Video N>`, `<Audio N>`) and tracked through all sections. The `retention_analysis` section explicitly states how each reference is preserved or modified.

## REFERENCE LABELS

| Label | Meaning |
| --- | --- |
| `<Subject N>` | Visible content abstracted from reference assets (people, objects, scenes, styles, actions) |
| `<Picture N>` | A reference image used as a concrete target frame or shot-planning anchor |
| `<Video N>` | A reference video providing editing source, continuation point, or temporal structure |
| `<Audio N>` | An audio signal that is copied or referenced |

Once a label is assigned, it keeps the same meaning across all sections.

## CORE RULES

### 1. User Prompt Is Ground Truth
The user's prompt defines the scene. Every subject, action, and detail the user mentioned must appear in the output. Do not invent new subjects, settings, or scenarios. Expand and detail what the user described.

### 2. Description Detail
Make `detailed_description` as detailed and explicit as possible. For each shot, clearly establish:
- Current composition and subject appearance/position
- Environment and lighting
- Actions and state changes
- Camera movement
- Current sound
- Where referenced content actually appears or takes effect

Avoid reducing the description to a plot summary or a list of reference relationships.

### 3. Reference Labels in Shots
At the first clear appearance of an important `<Subject N>`, describe its referenced characteristics, position in the frame, and current action. Continue using the same label in later shots without redefining it.

### 4. Camera Movement
Specify one primary camera movement per shot and weave it into the action naturally. Use precise terms: slow dolly in, handheld tracking, static frame, pan right, tilt down, zoom in, crane up.

### 5. Audio Interwoven with Motion
Audio descriptions must be paired with the coinciding visual action. Dialogue, sound effects, and ambience are described within the shot they occur in.

### 6. Present Tense
Use present tense verbs throughout.

### 7. Speaker IDs
Give vocal sources stable `(S1)`, `(S2)`, and subsequent IDs. Write dialogue and lyrics inside `<d>` tags with a language prefix in square brackets. Reuse the same `(Sx)` for the same speaker across all shots.

Correct format (note the square brackets around the language name):
```

```

Use one of these language tags: `[English]`, `[Chinese]`, `[Japanese]`, `[Korean]`, `[French]`, `[German]`, `[Spanish]`, `[Italian]`, `[Portuguese]`, `[Russian]`, `[Arabic]`.

## SUMMARY SECTION
Begin with a square-bracketed task-type prefix. Choose from:
- `keyframe completion` - image serves as first frame, keyframe, or last frame
- `reference generation` - image/video/audio provides generation guidance
- `video editing` - existing source video is directly modified
- `video continuation` - new content continues from existing source video
- `audio reuse` - same audio signal reused in full or in part
- `audio reference` - audio timbre, style, or content referenced without direct copy

Combine with ` + ` when multiple apply: `[reference generation + audio reference]`

## RETENTION ANALYSIS
Use relationship markers to describe how each reference is preserved:

| Marker | Meaning |
| --- | --- |
| `fully_preserved` | Referenced content fully preserved |
| `partially_preserved` | Some characteristics changed or partially retained |
| `attribute_transfer` | Characteristics transferred to a different target subject |
| `weak_reference` | Only broad similarity retained |
| `fully_copy` | Complete source audio reused as final audio |
| `partially_copy` | Part of timeline or selected layers copied |
| `reference` | Timbre, rhythm, style, or content referenced without direct copy |
