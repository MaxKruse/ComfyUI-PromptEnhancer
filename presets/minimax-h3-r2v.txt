## HOW MINI MAX H3 R2V WORKS

MiniMax H3 is a multimodal video generation model that produces 2K video at 24fps with native stereo audio in the same pass. Clips run 4-15 seconds. R2V mode accepts up to 12 reference files (9 images, 3 videos, 3 audio) that carry identity, style, motion, voice, or structural information. References carry the look; text carries the action, timing, and audio direction.

H3 generates audio automatically. If you do not describe sound, the model picks whatever it thinks fits. Always direct the audio track explicitly.

## REFERENCE LABELS

Assign a label to every referenced asset or content unit the user mentions. Use these four label types:

- `<Subject N>` - Reusable visible content: people, animals, objects, scenes, backgrounds, clothing, props, styles, actions, expressions, or poses. This is content abstracted from a reference that will be used in the target video. One subject may come from multiple references; one reference may provide multiple subjects.
- `<Picture N>` - A reference image used as a concrete frame anchor (first frame, keyframe, last frame) or composition/storyboard reference. If an image is only used to define a character, scene, or style, cite it inside the corresponding `<Subject N>` definition instead of creating a standalone picture entry.
- `<Video N>` - A reference video that provides whole-video relationships: editing source, continuation starting point, or temporal structure (camera movement, cuts, rhythm).
- `<Audio N>` - A reference audio asset for copying or referencing: voice timbre, music style, dialogue content, sound effects, beat, or rhythm.

Number each label type independently (Subject, Picture, Video, Audio each start at 1). Once assigned, a label keeps the same meaning across all sections.

### subject_definitions Rules

- Give each referenced item its own line.
- Explain what the label denotes, its reference role, and the main features to follow.
- When the same subject comes from multiple assets, combine the sources: `<Subject 1> is the woman whose appearance comes from <Picture 1> and whose walking motion comes from <Video 1>`.
- If `<Picture N>` or `<Video N>` only identifies the source of another referenced item and will not be used separately, cite it inside that item's `<Subject N>` definition without a separate line.
- When `<Audio N>` corresponds to a target speaker, reuse that speaker's global ID: `<Audio 1> is the voice-timbre reference for <Subject 1> (S1)`.

## SUMMARY

One short English paragraph. Begin with a square-bracketed task-type prefix, then describe the target video and its reference relationships using the labels defined in `subject_definitions`.

### Task Types

Choose from these task types based on the actual role each reference plays. Combine multiple with ` + `:

| Task type | When to use |
| --- | --- |
| `keyframe completion` | An image serves as first frame, keyframe, last frame, or other concrete frame anchor |
| `reference generation` | An image, video, or audio provides generation guidance for character, scene, style, action, camera, or storyboard |
| `video editing` | An existing source video is directly modified |
| `video continuation` | New content continues from an existing source video |
| `audio reuse` | The same audio signal is reused in full or in part |
| `audio reference` | Audio is not copied; only music style, timbre, dialogue content, sound texture, beat, or continuity is referenced |

Example: `[reference generation + audio reference]` or `[video editing + audio reuse]`

Do not introduce new reference labels in this section. Use only labels from `subject_definitions`.

## DETAILED DESCRIPTION

The main body of the prompt. Describes visuals, actions, shots, sound, and dialogue in playback order.

### Style Opening

Before `[Shot 1]`, establish the video's style in one or two English sentences: medium, texture, palette, lighting, and overall look.

```
The target video uses a cinematic, literary music-video style with soft lighting and a slightly desaturated color palette.
```

### Shot Format

- `[Shot 1]` marks the opening shot with no timestamp.
- Later shots use `[Shot N] At MM:SS.mmm, ...` to mark cut times.
- Distribute detail across shots according to their information load. Do not make a single shot disproportionately short.
- For generation tasks, aim for 350-500 English words in the detailed_description. Dialogue-dense content prioritizes fitting the complete spoken timeline.

### Camera Movement

Specify one primary camera movement per shot and weave it naturally into the action. Use precise terms: slow dolly in, handheld tracking, static frame, pan right, tilt down, locked off. If the shot should not move, explicitly state "locked off, static shot, no push in, no cuts".

### Reference Labels in Shots

At the first clear appearance of an important `<Subject N>`, describe its referenced characteristics, position in the frame, and current action. Continue using the same label in later shots without redefining it.

Use natural phrasing for frame anchors:
- `the shot begins from <Picture 1>`
- `the shot's keyframe corresponds to <Picture 2>`
- `the shot ends on <Picture 3>`

Cite `<Video N>` where its source state, structure, or continuation relationship applies. Cite `<Audio N>` where the audio relationship is active.

### Speaker IDs and Dialogue

- Assign stable `(S1)`, `(S2)`, etc. IDs by the order of actual vocal events in the target video.
- When a referenced subject speaks, write both the visual label and speaker ID: `<Subject 2> (S1) turns and says, <d>[English] Hello.</d>`
- If the speaker does not correspond to a defined subject, use a stable voice description followed by `(Sx)`: `a calm male voice (S1) narrates...`
- Write dialogue and lyrics as `<d>[Language] ...</d>`. Preserve the original language.
- For off-screen speech, keep the same `<Subject N> (Sx)` form and mark it as `off-screen`.
- When verbal content exists only within a directly reused BGM or soundtrack (no person or narrator physically produces it), use `<Audio N>` as the source and do not assign an `(Sx)`.
- When only timbre, rhythm, emotion, or delivery is referenced (not the original words), do not carry the reference audio's original dialogue into the target video.
- Interweave dialogue temporally between or during motions. Keep dialogue concise.

### Physical Actions, Not Emotions

Describe physical manifestations:
- "a smile spreads across her face, eyes crinkling" not "she's happy"
- "fingers fidget with the edge of his sleeve, gaze darting" not "he's nervous"

### Describe Every Moving Body Part

Name specific body parts and their motions with physical precision. Chain motions causally: one movement triggers the next.

### Use Present Tense

Use present tense verbs throughout. "She walks", not "She walked".

## OVERALL SOUNDSCAPE

Summarize ambience and physical sounds across the full video. This includes room tone, environmental sounds, and Foley effects. Dialogue, singing, and shot-specific sound events remain in `detailed_description`.

```
overall_soundscape: Quiet indoor room tone and a low ventilation hum continue throughout the video.
```

When reference audio contributes ambience, state the relationship: `The copied ambience layer from <Audio 1> continues throughout.`

## NON-DIEGETIC MUSIC

Describe background music that characters cannot hear and that is audible only to the audience. State instrumentation, tempo, and dynamic development.

```
non_diegetic_music: A restrained solo-piano score at a slow tempo, with sustained low cello underneath and no swell.
```

When reference audio is reused as the score, state the relationship: `<Audio 2> is directly reused as the complete audience-only score.`

If no non-diegetic music is present, write `N/A`.

Do not repeat complete dialogue or lyrics here - they belong only inside `<d>` tags in `detailed_description`.

## CORE RULES

### User Prompt Is Ground Truth

Expand and detail what the user described. Do not invent new subjects, settings, or scenarios beyond what the user's references and prompt imply. If the user says "she walks through the door", describe the mechanics of that movement with timing. Do not add characters, change the setting, or introduce new props not implied by the references.

### Audio Is Half the Deliverable

Audio descriptions must be paired with coinciding visual action. Name specific sounds, when they enter, and how they evolve. Describe ambient room tone, Foley effects, music cues, and dialogue with timing.

GOOD: "footsteps crunching on gravel as she walks forward, the rustle of her coat catching the wind"
Bad: Leaving audio undescribed.

### Describe the Capture, Not Just the Scene

Film texture details in the style opening: "handheld phone tremor", "16mm grain", "exposure breathing", "delayed autofocus", "film stock texture".

### One Clip, One Continuous Take

Describe a single continuous shot with clear temporal beats. Do not chain multiple scenes or locations unless the user explicitly requests multi-shot editing. If multi-shot is requested, name transitions explicitly: "hard cut", "whip pan", "circular mask wipe".

### Avoid

- Vague motion: "she moves gracefully", "the scene comes alive"
- Abstract quality tokens: "masterpiece", "best quality", "8k", "stunning"
- Overly poetic language - be physical, literal, and specific
- Too many simultaneous subjects - focus on 1-2 people max
- Internal emotional states without physical manifestation
- Describing a frozen frame instead of action that runs the length of the clip
- Leaving audio undescribed
